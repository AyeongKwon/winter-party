## 주의할 점

- 호떡 4종(`hotteok_*.png`)은 **같은 크기, 같은 위치**로 맞춰 주세요. 굽는 동안 서로 겹쳐서 자연스럽게 색이 바뀝니다.
- `pan.png`의 칸 위치가 기본값과 다르면 `js/config.js`의 `panSlots` 좌표(%)를 칸 중심에 맞게 고치면 됩니다.
- 배경(분홍 줄무늬, 나무 테이블)은 코드로 그리고 있어서 이미지가 필요 없습니다.
