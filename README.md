# 🍢 겨울 간식 포장마차

붕어빵, 호떡, 어묵을 만들어 손님에게 파는 웹 게임입니다.
빌드 없이 HTML, CSS, JavaScript만으로 동작해요. `index.html`을 열면 바로 실행됩니다.

## 게임 규칙

- 메뉴에서 간식 하나를 골라 가게를 열어요.
- 손님은 최대 2명까지 줄을 서고, 항상 **맨 앞 손님**에게 줍니다.
- 손님은 1~5개를 주문해요. 붕어빵 손님은 팥과 슈크림을 섞어서 주문하기도 해요.
- 손님의 인내심이 다 떨어지면 하트가 1개 줄어요. 하트 3개가 모두 없어지면 끝!
- 시간이 지날수록 손님이 더 자주 와요.

| 간식 | 가격 |
|---|---|
| 붕어빵 | 1,000원 |
| 호떡 | 2,000원 |
| 어묵 | 500원 |

## 튜토리얼

간식을 처음 고르면 튜토리얼이 자동으로 시작돼요. 할머니 사장님이 단계마다 무엇을 누를지 알려주고,
해야 할 작업대가 반짝여요. 튜토리얼 중에는 손님이 재촉하지 않고 하트도 줄지 않아요.
메뉴의 **튜토리얼** 버튼이나 <kbd>T</kbd> 키로 언제든 다시 볼 수 있어요.

## 조작

| 동작 | 키보드 | 마우스 | 폰 |
|---|---|---|---|
| 작업대 고르기 | ← → (또는 숫자 1~6) | 작업대 클릭 | 작업대 탭 |
| 하기 | 스페이스 | 클릭 | 탭 |
| 꾹 누르기 (붓기, 누르기) | 스페이스 꾹 | 꾹 클릭 | 길게 누르기 |
| 연타 (젓기, 손질) | 스페이스 연타 | 연타 | 연타 또는 문지르기 |
| 고르기·조절 (팥/슈, 불 세기, 지그재그) | ↑ ↓ | 화면의 ▲▼ 버튼 | 화면의 ▲▼ 버튼 |
| 손님에게 주기 | 엔터 (붕어빵은 주기 칸에서 ↑ 팥 / ↓ 슈) | 접시나 손님 클릭 | 접시나 손님 탭 |
| 메뉴로 | Esc | 메뉴 버튼 | 메뉴 버튼 |

화면 맨 아래 안내 줄에 지금 고른 작업대에서 무엇을 누르면 되는지 항상 나와요.

## 간식별 만드는 과정

**🐟 붕어빵** (틀 3칸)
반죽 붓기(꾹, 초록에서 떼기) → 속 넣기(↑ 팥 / ↓ 슈크림) → 반죽 덮기(꾹) → 틀 덮기 → 노릇하면 뒤집기 → 노릇하면 꺼내기

**🥞 호떡** (철판 3칸)
반죽 젓기(연타) → 반죽 동그랗게 만지기(연타) → 철판에 올리기 → 꾹 눌러 납작하게 → 뒤집기 → 꺼내기

**🍢 어묵**
- 꼬치: 화면에 뜨는 ↑↓ 순서대로 눌러 지그재그로 꽂기 (틀리면 처음부터)
- 냄비: 물 붓기(꾹) → 무 손질(연타) → 꽃게 손질(연타) → 불 조절(↑↓)로 온도를 초록 구간에 맞춰 끓이기 → 국물 6그릇 완성
- 그릇: 꼬치 + 국물 담기(꾹)

## 실행하기

`index.html`을 브라우저에서 열면 됩니다.

폰으로 테스트하려면:
```bash
python3 -m http.server 8000
# 같은 와이파이의 폰에서 http://<컴퓨터 IP>:8000
```

## 테스트

봇이 세 간식을 자동으로 플레이해서 규칙이 잘 돌아가는지 확인합니다. (Node.js 필요)
```bash
node tests/sim.js
```

## 난이도 조정

`js/config.js` 숫자만 바꾸면 돼요.

| 값 | 의미 |
|---|---|
| `common.patienceMultiplier` | ★ 모든 손님의 인내심 배율 (1.5 = 1.5배 오래 기다림) |
| `common.maxCustomers` | 동시에 기다리는 손님 수 (기본 2) |
| `common.spawnIntervalStart / Min` | 손님 등장 간격 (처음 18초 → 최소 8초) |
| `snacks.*.price` | 간식 가격 |
| `snacks.*.patienceBase / patiencePerItem` | 손님 인내심 |
| `snacks.hotteok.stirTaps / shapeTaps` | 젓기·만지기에 필요한 연타 수 |
| `snacks.eomuk.skewerSteps` | 꼬치 하나에 필요한 지그재그 횟수 |
| `snacks.eomuk.servingsPerPot` | 국물 한 솥으로 담는 그릇 수 |

최고 기록은 간식별로 브라우저에 저장돼요.
